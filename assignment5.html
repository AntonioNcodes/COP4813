Assignment 5 - Spirograph

This assignment uses HTML5 Canvas and JavaScript to create an animated Spirograph drawing.

The position of the pen is calculated using the Spirograph equations provided in the assignment. The values for the outer radius, inner radius, and pen offset can be changed before starting the drawing.

Spirograph Controls

R must be greater than or equal to r. R and r must be greater than 0. O must be 0 or greater.
