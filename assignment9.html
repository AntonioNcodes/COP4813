How to play: Wait for the 3-second opening animation to finish. Click and drag from the golf ball in the direction you want to shoot, then release the mouse. Drag farther for more power. The ball slows down on grass and sand. Get it into the hole to complete the game. Use New Game to restart.

About This Assignment

This project demonstrates JavaScript animation using HTML5 canvas. The golf ball automatically moves diagonally and bounces off the course boundaries during the opening animation. Mouse and pointer events allow the player to aim and shoot. Friction slows the ball, and a shot counter tracks attempts.
