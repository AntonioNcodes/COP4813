About This Assignment

This project demonstrates JavaScript animation and mouse-click interaction using the HTML canvas. A moving target travels diagonally across a bounded rectangular area and bounces when it reaches the edges.

Users can click the cyan mirrors to rotate them and change the direction of the laser beams. The reset button restores the original mirror positions and target movement.

JavaScript Concepts Demonstrated

  • HTML canvas drawing
  • Timer-based animation using requestAnimationFrame()
  • Object movement and boundary collision detection
  • Mouse-click event handling
  • Coordinate calculations and laser reflection
