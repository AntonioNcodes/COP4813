About This Assignment

This project demonstrates JavaScript animation using the HTML5 canvas. The golf ball moves diagonally across the course and bounces off the boundaries. Mouse-click events allow the player to hit the ball, changing its direction and color. This demonstrates client-side scripting and interactive animation using JavaScript.
