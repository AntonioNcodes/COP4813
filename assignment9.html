About This Assignment

This project demonstrates client-side JavaScript and HTML5 canvas animation. The golf ball moves diagonally across the course and bounces off the canvas boundaries. Mouse-click events allow the player to change the ball's direction and color. The project also demonstrates JavaScript event listeners, drawing functions, and animation using requestAnimationFrame().
