About This Assignment

This project demonstrates JavaScript animation using the HTML5 canvas. The golf ball moves automatically during the opening animation and bounces off the course boundaries. Players can aim and shoot using mouse or touch interactions. The game also features obstacles, sand friction, collectible power-ups, scoring, and three levels.
